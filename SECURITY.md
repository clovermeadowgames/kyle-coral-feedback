# Security Policy

This repository collects gameplay feedback, so most reports belong in a normal [issue](../../issues/new/choose).

Found a genuine security or privacy problem (something that exposes another player's data, say, or a way to run code through the game)? Please don't post the details in a public issue. Instead, use GitHub's [Report a vulnerability](../../security/advisories/new) form for a private disclosure, and we'll respond as fast as we can.

Thanks for reporting responsibly.

# 🐚 Kyle Coral Playtester Feedback

Thanks for helping test [Kyle Coral](https://clovermeadowgames.com/kyle-coral). This is the public spot for bug reports and feedback on the demo. No account approvals or permissions needed; just open an issue.

Kyle Coral is an underwater cave-diving adventure: hold your breath, thread a flooded cave, refill at air pockets, and get back to the surface before your air runs out.

## Found a bug? The fast way

In the game, press **Esc** → **Report a Bug**. That opens a report with your seed, level, biome, and version already filled in, so we can regenerate your exact cave and see the problem ourselves. Say what happened, hit Submit, done.

## Rather write it up yourself?

**[Open a new report](https://github.com/clovermeadowgames/kyle-coral-feedback/issues/new/choose)** and pick the template:

| Template | Use it when |
| --- | --- |
| Report a bug | Something broke, froze, got you stuck, or looked wrong. |
| Balance feedback | Too hard, too easy, or a difficulty spike that felt cheap. |
| Design question | "Wait, is it supposed to work this way?" |
| Feature request | An idea that'd make the dive better. |

## The Game info field

The bug form has a **Game info** field. In the game, press **Esc** and click **Copy Bug Info** (or **Copy Info** under Debug), then paste it in. It carries the seed. That's the most useful thing you can send, because it lets us load the exact cave you were in. Can't find the button? Type the version (bottom corner of the title screen) and the level number, and send it anyway.

## What happens next

A human reads every report. Ones filed from the in-game button come in tagged `playtest`. We reproduce it from your seed and tag it `confirmed` (or ask for more with `needs-repro`). When a fix is queued, we tag it `ported` and keep the thread updated so you can watch it land. You'll get notified right on your issue.

When a report is especially sharp (a clean repro, a nasty edge case, a clip that nails it), we tag it `great-catch`. Every seed you send makes the game better.

## A couple of notes

# 🐚 Kyle Coral — Playtester Feedback

Welcome, diver — and **thank you for helping us make [Kyle Coral](https://github.com/clovermeadowgames/kyle-coral-feedback) better.**

**Kyle Coral** is a hand-crafted **underwater cave-diving adventure** built in Godot: hold your
breath, thread twisting procedural caves, refill at air pockets, and race the deep back to the
surface. This is the **public home for bug reports and feedback** on the demo.

> 📮 **You do _not_ need any special access to file here.** No account approvals, no repo
> permissions — just open an issue. This repo exists precisely so anyone playtesting the demo can
> reach us in one click.

---

## 🐛 Found a bug? The one-click way

**In the game:** press **`Esc`** → click **`Report a Bug`**.

That opens a report with your **seed, level, biome, and version already filled in** — so we can
regenerate your _exact_ cave and see the problem ourselves. Just tell us what happened and hit
**Submit**. That's it. 🎉

## ✍️ Prefer to write it yourself?

**[→ Open a new report](https://github.com/clovermeadowgames/kyle-coral-feedback/issues/new/choose)**
and pick the template that fits:

| Template | Use it when… |
| --- | --- |
| 🐛 **Report a bug** | Something broke, froze, got you stuck, or looked wrong. |
| ⚖️ **Balance feedback** | Too hard, too easy, or a difficulty spike that felt *cheap*. |
| 🤔 **Design question** | "Wait — is it *supposed* to work this way?" |
| ✨ **Feature request** | An idea that would make the dive better. |

## 🪄 The "magic box"

The bug form has a **Game info** field. To fill it:

> In the game, press **`Esc`** and click **`Copy Bug Info`** (or **`Copy Info`** under `Debug…`),
> then **paste** it into the box.

It carries the **seed** — the single most useful thing in any report, because it lets us load the
same cave you were in. Can't find the button? Just type the **version** (bottom corner of the
title screen) and the **level number**, and send it anyway. 💙

---

## 🔎 What happens after you file

Every report is read by a human. Here's the journey:

1. Reports filed from the in-game button arrive tagged **`playtest`** so we can triage them as a batch.
2. We reproduce it from your seed and tag it **`confirmed`** (or ask for a bit more with **`needs-repro`**).
3. Once a fix is queued in our development tracker, we tag the report **`ported`** and keep this
   thread updated so you can see it land.

You'll get notified right here on your issue as it moves along.

---

## 📌 A couple of notes

- **This repo is for feedback only.** The game's source code lives elsewhere — please **don't open
  code pull requests here** (see [`CONTRIBUTING.md`](CONTRIBUTING.md)). Bug reports and ideas are
  exactly what we want.
- **One thing per report, please.** It keeps each fix easy to track and easy to celebrate.
- **Screenshots help a lot** — but always describe it in words too, so our tools can read it.

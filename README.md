# Kyle Coral — Playtester Feedback

Public bug & feedback intake for the **Kyle Coral** demo. File reports here — you do
**not** need any access to the game's source repository.

## How to report

Easiest: **in the game, press `Esc` → `Report a Bug`.** It opens a pre-filled form with
your seed, level and version already attached — just add what happened and submit.

Or open an issue here and pick a template:

- 🐛 **Report a bug** — something broke, froze, got stuck, or looked wrong.
- ⚖️ **Balance feedback** — too hard, too easy, a spike that felt cheap.
- 🤔 **Design question** — "should this work this way?"
- ✨ **Feature request** — an idea for the game.

### The magic box 🪄
The bug form has a **Game info** box. In the game, press `Esc` and click **`Copy Bug Info`**
(or `Copy Info` under `Debug…`), then paste it in. It carries the **seed**, which lets us
regenerate your exact cave and see the bug ourselves — please include it.
